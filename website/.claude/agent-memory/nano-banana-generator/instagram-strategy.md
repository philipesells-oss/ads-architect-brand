## Design Standards (All Posts)

**Colors:**
- Background: #0A0A0A (Obsidian)
- Accent: #00D4AA (Signal Teal)
- Secondary: #111111 (Carbon)
- Text primary: #FAFAFA
- Text secondary: #A1A1AA
- Problem state: #D43F3F (Red)

**Typography:**
- Headlines: Inter Bold (700)
- Body: Inter Regular (400)
- Metrics: JetBrains Mono Bold (700)

**Aesthetic:**
- Reference: Vercel, Linear, Stripe
- No photography required
- All graphic/typographic designs
- SaaS-level polish, minimal dark theme

## Key Deliverables per Brief

Each design brief includes:
1. Post concept/title
2. Exact visual layout (pixel positions, dimensions)
3. Text elements (headlines, subtexts, metrics)
4. Color usage breakdown
5. Content pillar category
6. Detailed Midjourney v6 prompt for AI generation

## Posting Strategy

**1:1 Posts:** Tuesday/Thursday 9 AM WITA (Bali time)
**9:16 Reels:** Wednesday/Saturday 7 PM WITA (max reach windows)

All CTAs route to audit booking, DM conversion, or "meet the team" links.

## Design Execution Notes

- Canvas: 1080×1080 (square) or 1080×1920 (vertical)
- Export: PNG (transparent) or JPG (flat), 72 DPI
- Mobile preview required at 320px width
- Accessibility: Min contrast 4.5:1 for text
- All design metrics/claims require backing case studies
